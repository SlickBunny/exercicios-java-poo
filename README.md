# Exercícios de Programação Orientada a Objetos (POO)

Este repositório contém os exercícios iniciais da disciplina de Programação Orientada a Objetos. Os códigos foram desenvolvidos em Java e têm como objetivo praticar a sintaxe básica, o processo de compilação, execução e o tratamento de erros na linguagem.
